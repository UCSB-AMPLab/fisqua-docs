# Importaciones

<p class="lede">Incorpora registros de catálogo a un espacio de trabajo desde una hoja de cálculo: una operación revisada y reversible.</p>

El módulo de importaciones incorpora registros de catálogo a un espacio de
trabajo desde un CSV, como una secuencia de pasos definida: **Carga → Perfil →
Verificación → Simulación → Importación**, con su historial y una **reversión**
completa. El catálogo no se modifica hasta el paso de importación, y toda
importación se puede deshacer.

Esta sección recorre cada paso:

- **[Carga](carga/)**: prepara un CSV, validado al entrar.
- **[Perfil](perfil/)**: vincula tus columnas con los campos de descripción de
  Fisqua.
- **[Verificación](verificacion/)**: muestra todos los problemas antes de
  ejecutar nada.
- **[Simulación](simulacion/)**: clasifica cada fila sin escribir nada.
- **[Importación](importacion/)**: confirma las filas revisadas como una
  ejecución registrada.
- **[Ejecuciones](ejecuciones/)**: la constancia permanente de cada importación.
- **[Reversión](reversion/)**: deshace una importación terminada sin borrarla.
